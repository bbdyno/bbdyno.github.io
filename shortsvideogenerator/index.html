ShortsVideoGenerator

개인이 운영하는 short-form 영상 제작·업로드 도구
A personal tool for producing and uploading short-form videos

무엇을 하는 도구인가

주제를 정하면 자료 조사부터 대본, 나레이션, 영상 클립, 자막, 배경음까지 이어 붙여 세로형 영상 한 편을 만들고, 운영자 본인의 YouTube 채널에 올립니다. 운영자의 컴퓨터에서만 실행되는 개인용 도구이며 서비스로 제공되지 않습니다.

Given a topic, it researches, writes a script, generates narration, video clips, subtitles and background audio, assembles a vertical video, and uploads it to the operator's own YouTube channel. It runs only on the operator's computer and is not offered as a service to anyone else.

YouTube API 사용

영상 업로드, 썸네일 설정, 자막 트랙 등록, 공개 범위 변경, 조회수 확인에 YouTube Data API v3을 사용합니다. 운영자 본인의 채널에만 접근합니다. 자세한 내용은 개인정보처리방침을 참고하세요.

It uses the YouTube Data API v3 to upload videos, set thumbnails, add caption tracks, change privacy status, and read view counts — on the operator's own channel only.
