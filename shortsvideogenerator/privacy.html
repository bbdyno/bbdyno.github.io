Privacy Policy for ShortsVideoGenerator · Effective September 13, 2026

1. 개요

ShortsVideoGenerator(이하 "본 도구")는 개인이 자신의 YouTube 채널에 올릴 short-form 영상을 만들고 업로드하기 위해 사용하는 개인용 도구입니다. 운영자 본인의 컴퓨터에서만 실행되며, 서버를 두지 않고 다른 사용자를 받지 않습니다.

ShortsVideoGenerator is a personal tool used by its operator to create and upload short-form videos to the operator's own YouTube channel. It runs only on the operator's own computer. It has no server and accepts no other users.

2. 접근하는 Google 사용자 데이터

본 도구는 운영자 본인의 Google 계정에만 접근하며, 다음 권한(범위)을 사용합니다.

범위사용 목적
.../auth/youtube.upload운영자 본인 채널에 영상 파일을 업로드합니다.
.../auth/youtube.force-ssl업로드한 영상의 제목·설명·태그 수정, 썸네일 설정, 자막 트랙 등록, 공개 범위 변경, 조회수 확인에 사용합니다.

본 도구는 다른 사람의 채널이나 데이터에 접근하지 않으며, Gmail·연락처·드라이브 등 다른 Google 서비스의 데이터에 접근하지 않습니다.

The tool accesses only the operator's own Google account, using the two scopes above. It does not access anyone else's channel or data, and does not access Gmail, Contacts, Drive, or any other Google service.

3. Google 사용자 데이터의 제한적 사용

본 도구의 Google 사용자 데이터 사용 및 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다. 취득한 데이터는 위 2항에 적은 기능을 제공하는 목적으로만 쓰이며, 광고 목적으로 사용하거나 제3자에게 판매·양도하지 않습니다. 사람이 해당 데이터를 열람하지 않습니다.

Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data is used solely to provide the features described in section 2. It is never used for advertising, sold, or transferred to third parties, and it is not read by humans.

4. 보관과 삭제

  • OAuth 인증 토큰은 운영자 컴퓨터의 로컬 파일에만 저장되며 외부로 전송되지 않습니다.
  • 업로드에 사용한 영상·자막 파일은 운영자 컴퓨터에 보관되며, 운영자가 임의로 삭제합니다.
  • 본 도구는 분석 도구를 쓰지 않고, 방문자 정보를 수집하지 않으며, 쿠키를 사용하지 않습니다.

OAuth tokens are stored only in a local file on the operator's computer and are never transmitted elsewhere. Video and caption files live on that computer and are deleted at the operator's discretion. The tool uses no analytics, collects no visitor information, and sets no cookies.

5. 접근 권한 철회

운영자는 Google 계정 > 타사 앱 및 서비스에서 언제든지 본 도구의 접근 권한을 해제할 수 있습니다. 해제하면 저장된 토큰은 즉시 무효가 됩니다.

6. 변경

본 방침이 변경되면 이 페이지에 갱신된 내용과 시행일을 게시합니다.
